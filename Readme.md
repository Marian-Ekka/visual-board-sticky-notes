
# **Visual Board — Interactive Web Platform**

##  Project Overview

**Visual Board** is an interactive, client-side web application developed as part of the **Web Technology** course.
It serves as a digital board where users can dynamically create, style, organize, and manage virtual sticky notes.
The project emphasizes using the World Wide Web as a platform for interactive applications, focusing on **HTML5**, **CSS3**, and **JavaScript**.

---

##  Key Features

### Dynamic Note System

* Create sticky notes instantly through DOM manipulation.
* Supports deleting and editing notes.

###  Advanced Styling 

* **Custom Web Colors**: Choose note background colors using hex codes or a color picker.
* **Fancy Borders & Shapes**: Circular, square, portrait notes using `border-radius`, `box-shadow`, and other CSS effects.
* **Typography**: Uses modern web fonts (Montserrat, Poppins) for a clean and contemporary design.

###  Interactivity

* **Draggable Interface**: Move notes around the board with custom JavaScript event handling.
* **Sticker System**: Add emojis and symbols to categorize notes visually.
* **Checklist Mode**: Create toggleable task lists inside notes for productivity.

###  Archive View

* Switch between board mode and an **Archive View** rendered using **HTML Tables**.
* Highlight archived notes using custom cell coloring.
* Clean table layout using `border-collapse` and structured CSS formatting.

---

## Technical Stack

* **HTML5** — Semantic structure and page layout
* **CSS3** — Visual styling, gradients, fonts, and box model
* **Vanilla JavaScript** — Interactivity, DOM operations, event listeners, and dynamic rendering
